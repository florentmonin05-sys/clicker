RANDOM CLICKER - projet Android Studio

1. Ouvre le dossier RandomClicker dans Android Studio (attends la synchro Gradle).
2. Build > Build Bundle(s) / APK(s) > Build APK(s)
   -> app/build/outputs/apk/debug/app-debug.apk
   (ou branche ton S23 en debogage USB et clique sur Run)
3. Installe l'APK sur le telephone.
4. Ouvre l'app > "Activer le service d'accessibilite" > Applications installees > Random Clicker > ON.
   Si c'est grise : Parametres > Applications > Random Clicker > menu ⋮ > "Autoriser les parametres restreints", puis reessaie.
